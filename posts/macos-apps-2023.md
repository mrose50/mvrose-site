I have been using macOS as my primary operating system for over twenty years. During this time, I have tested various applications and wanted to highlight some of my favorites.

*This is not a paid promotion. I simply enjoy these apps and want to share them.*

## Favorite Apps

🌎 **Arc** — After switching from Google Chrome, I found my perfect web browser. Exceptional interface design and tab organization.

📅 **Fantastical** — A calendar app living in the menubar that enables rapid event and reminder creation through natural language processing.

📷 **CleanShot X** — A screenshot enhancement tool with quick access and annotation features that streamlines documentation workflows.

🧲 **Magnet** — Window management utility particularly beneficial for ultrawide monitor setups, featuring keyboard-driven arrangement shortcuts.

📊 **Stats** — An open source app displaying CPU, GPU, and memory usage data directly in the menu bar.

☕️ **Amphetamine** — Prevents device sleep during specific scenarios such as large downloads or intensive tasks.

🧹 **AppCleaner** — Comprehensive uninstallation utility that removes applications and all associated files scattered throughout the system.

🤵 **Bartender** — Organizes menu bar clutter by selectively displaying only desired applications.

🧽 **Unclutter** — Enhances productivity through clipboard history, recent files access, and integrated scratchpad functionality.

🎧 **Endel** — Focus music app with convenient menu bar controls.

⌨️ **Pure Paste** — Pastes text in plain format by default, eliminating formatting inconsistencies.

✅ **Reminders** — The native macOS task management app has significantly evolved and simplified task tracking.

📔 **Notes** — Apple's default note-taking app offering simplicity and seamless cross-device synchronization.

🧱 **LuLu** — A free, open-source firewall blocking unknown outgoing connections and monitoring network activity.

❌ **BlockBlock** — Monitors persistence locations and alerts when system components are added.

🔒 **1Password** — A password manager featuring intuitive design and enhanced security capabilities.

💽 **MacUpdater** — Automatically tracks third-party software updates and streamlines the update process.

🎩 **Alfred** — My most frequently used application. This Spotlight replacement offers powerful productivity workflows.

- **alfred-1password-workflow** — Searches and accesses 1Password items
- **alfred-2fa-read-code** — Views and copies 2FA codes from messages
- **alfred-calm-notifications** — Toggles focus mode via keywords
- **alfred-dente-azul** — Manages Bluetooth connectivity
- **alfred-network-workflow** — Manages Wi-Fi, Ethernet, VPN, and DNS settings
