## Hardware Modifications

**2TB M.2 2230 NVMe SSD** — An upgrade from the standard 1TB drive, cloned using an NVMe SSD Enclosure. Detailed instructions are available from community resources.

**GuliKit Hall Effect Joysticks** — These replacements provide smooth performance and address stick drift concerns, with installation guided by video tutorials.

**JSAUX Transparent RGB Back Plate** — An aesthetic enhancement that also contributes to improved cooling performance.

**1TB Micro SD Card** — Dedicated storage for ROM files used in emulation.

**Deckbuttons** — Custom button replacements that require some technical skill but deliver impressive visual results.

## Software Enhancements

**Decky Loader** — A homebrew plugin launcher featuring utilities such as:
- Audio Loader for customizing UI sounds and background music
- AutoFlatpaks for managing applications without entering Desktop Mode
- HLTB for Deck displaying game length information
- ProtonDB Badges showing compatibility ratings
- SteamGridDB for customizing artwork
- VibrantDeck for screen adjustment controls

**EmuDeck** — Enables emulation of retro games on the device.

**Non-Steam Apps** — Desktop Mode allows adding applications like Firefox, Discord, and GeForce Now to Gaming Mode for seamless access.

## Accessories

The setup includes a wireless mechanical keyboard, mouse, controller, docking station, protective cases, screen protectors, thumb grips, and mounting solutions designed to enhance comfort during extended play sessions.

## Summary

While these enhancements are not essential, they significantly enhance your overall gaming experience.
